# Curriculum

**Bao Chinese v0.1 · HSK 3.0-aligned starter**

The course is sequenced by **communicative function**, not by the alphabetical HSK list. Each unit gives the learner something they can do in the real world, and every lesson introduces grammar through a pattern the learner can use immediately.

## Lesson anatomy

Each lesson is generated from structured content:

1. **Intro cards (5–7).** Hanzi, pinyin, English, tone contour, audio, one example sentence.
2. **Recognition drills (one per word).** Rotating meaning / character / listening questions.
3. **Tone check (when possible).** Single-syllable words only; audio-first.
4. **Match (4 pairs).** Bilingual linking.
5. **Sentence production (2).** Build the Chinese sentence from tiles.
6. **Fill in the blank (1).** Sentence-level recall with plausible distractors.
7. **Trace (1).** Write the first character of a word.
8. **Mistake replay.** Wrong items are requeued once at the end.

Typical length: 14–22 interactions, 5–8 minutes.

### Exercise types

| Type | Skill | Example |
| --- | --- | --- |
| `intro` | encode | 朋友 · péng you · friend |
| `meaning` | recognition | What does 朋友 mean? |
| `hanzi` | recognition | Which characters mean “friend”? |
| `audio` | listening | Listen and choose the word |
| `tone` | perception | Which tone do you hear? |
| `tone-word` | tone + meaning | shī / shí / shǐ / shì — which word did you hear? |
| `match` | linking | 你好 ↔ hello |
| `build` | syntax/production | “Are you a student?” → 你 是 学生 吗 |
| `fill` | recall in context | ? 不是学生 → 我 |
| `trace` | handwriting | Trace 你 |

Distractors are chosen from the same part of speech and similar character length where possible, so the learner cannot win by shape alone.

## Pinyin and tone conventions

- Data stores pinyin in **numbered form** (`ni3 hao3`) and renders tone marks (`nǐ hǎo`).
- Neutral tones are `5` (`ma5` → `ma`).
- Multi-syllable words display all tones, e.g. 朋友 → “2nd tone + neutral”.
- Tone sandhi is **not** silently rewritten. `你好` is shown as `nǐ hǎo` (dictionary form) even though it sounds like `ní hǎo`. A future pronunciation note will explain this.
- `一` and `不` are shown in dictionary tone; sandhi is flagged in grammar notes rather than changing every pinyin string.

This is a deliberate trade-off: consistent, testable data now; surface-phonetic transcription later.

## Authoring standards

1. **Every word is introduced exactly once.** `tools/validate-content.mjs` enforces this.
2. **Every non-punctuation token must be a dictionary word.** This guarantees pinyin can be generated and prevents accidental unknown characters.
3. **Every lesson word appears in at least one sentence.** No orphan vocabulary.
4. **Sentences are original** and written for this course; no copied textbook sentences.
5. **One grammar idea per lesson.** Pattern first, then a one-sentence explanation, then examples.
6. **HSK alignment is directional.** Words are drawn from the HSK 3.0 Level 1 list where possible; a few high-utility words (e.g. 北京, 天气) are included for communicative value.
7. **No tone-number typing in v1.** Pinyin production is planned with a tone pad, not a numeric keyboard.

Validated automatically:

```bash
node tools/validate-content.mjs
# ✓ content valid: 8 units, 24 lessons, 151 words, 128 sentences
```
